🦊 *Second Tail* moves outbound connections from sing-box to Xray. Your SOCKS5 clients can keep using the same group addresses and ports. You can now import VLESS links that use XHTTP, and native Xray outbound JSON retains its advanced transport settings.

Groups remain independent with the new core. If one group rejects a configuration change, a download already running through another group can finish on the same connection.

### Upgrading from v0.1.x

Plan a maintenance window for the first restart. With the supplied Docker Compose setup, stop the container and back up `./deployment-data/`. Keep the database together with its `.secret` file or, if you supplied your own key, the value of `KITSUNEGATE_SECRET`.

Set `KITSUNEGATE_IMAGE=ghcr.io/touka2014/kitsunegate:0.2.0` in your Compose `.env`. Pull the image and start the container from the same directory.

```bash
docker compose pull
docker compose up -d --no-build
```

On first startup, KitsuneGate checks each enabled node against Xray. If a configuration is incompatible, KitsuneGate disables that node and records the reason in its event history. You can edit the saved settings and re-enable it. Nodes that previously skipped TLS certificate verification need a trusted certificate or a SHA-256 certificate pin.
